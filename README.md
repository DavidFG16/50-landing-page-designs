# 50 Landing Pages Challenge – HTML & CSS Practice

This repository is a personal project where I challenged myself to build 50 static landing pages using only HTML and CSS. The designs are based on a [Figma community file](https://www.figma.com/community/file/1127302394641561751), with the goal of improving my layout and styling skills through repetition and variety.

## 🎯 Objective

The main objective of this project was to:

- Improve proficiency in **semantic HTML** and **modern CSS**
- Gain speed and consistency in **UI layout implementation**
- Simulate a real-world design-to-code workflow

## ✅ Progress

Out of the 50 proposed designs, I successfully built 15 landing pages. Each one is fully static and visually faithful to its Figma counterpart.

## 🛠️ Tools & Methodology

- **HTML5 & CSS3** (No JavaScript, no frameworks)
- **GitHub Projects** used to organize tasks using a **Kanban-style board**
- Solo development: no team, just personal learning and discipline

## 📂 Structure

Each landing page has its own folder with:

- `index.html`
- `style.css`
- Assets (if needed)

## 📌 Inspiration

Designs were taken from this [Figma file](https://www.figma.com/community/file/1127302394641561751) created for layout practice.
